# 可选的项目指引片段

在目标项目需要默认启用这套轻量流程时，将下面内容按实际路径合并到 AGENTS.md 或客户端支持的项目指引中。保留项目其他规则；若旧指引强制另一套框架，应在得到项目所有者授权后明确调整其适用范围。安装脚本不会修改项目指引。

```markdown
## CANN 算子开发

- 算子开发默认使用 cann-op-develop；通过客户端技能列表定位，或读取本项目保存的该技能 SKILL.md。
- 当前 Agent 直接完成调研、实现、测试和文档；不强制子 Agent、workflow YAML 或逐步骤审批。
- 集中确认影响语义、精度、范围与权限的缺项，沿用已确认事项；实现调整、补测和常规修复自主推进。
- 每版优化执行 cann-op-review；环境变动时使用 cann-op-env-check，提交阶段使用 cann-op-submit。
- 正确性先于性能，成功后才封存 demo；保留关键复现资产，支持文档与最终代码一致。
- 推送、发布 issue/PR 和评审回复按用户已有授权执行；不在文档中保存秘密。
```
